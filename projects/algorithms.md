# Enhancement 2: Algorithms and Data Structures
## CS330 - Computational Graphics and Visualization

## Overview

The second artifact is the final project from my CS 330 class. Created in Winter 2025, it's a C++ application that uses OpenGL and GLFW for rendering a 3D scene.

The project features:
- ViewManager class for scene management
- SceneManager for rendering
- Camera for 3D navigation
- Lighting and textures for realism
- A living room scene with television and carpeted flooring

## Key Enhancements

### Octree Partitioning System

The original code had performance issues in the RenderScene function. I implemented an octree partitioning system to:

1. Divide the 3D space into eight octants
2. Reduce rendering workload
3. Improve overall performance and efficiency

## Challenges and Solutions

### Challenge: Integration with Existing Code
**Solution:** Carefully integrated the octree system into the existing rendering pipeline while maintaining compatibility with the original SceneManager.

### Challenge: Performance Balance
**Solution:** Found the right balance between algorithmic complexity and practical implementation, ensuring the solution improved performance without adding unnecessary overhead.
